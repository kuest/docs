---
title: Locales
description: Enable and order site languages, and configure automatic translations for event titles, categories, and Rules.
icon: languages
---

<Info>
Supported locales are English (`en`), German (`de`), Spanish (`es`), Portuguese (`pt`), French (`fr`), Chinese (`zh`), Japanese (`ja`), Arabic (`ar`), Russian (`ru`), Italian (`it`), Polish (`pl`), and Korean (`ko`). English stays enabled as the default locale.
</Info>

<AccordionGroup>
  <Accordion title="Enable site languages" icon="globe" defaultOpen>
    Each switch controls whether that locale appears on the public site. English cannot be disabled. Only enable languages your team can actually review, support, and moderate.
  </Accordion>
  <Accordion title="Language order" icon="list-ordered">
    Drag a language or use its up and down buttons to change the language selector order. English stays first. Save the changes to apply the new order.
  </Accordion>
  <Accordion title="Automatic translations of event titles and categories" icon="sparkles">
    This switch translates event titles and category names into the enabled non-English locales. It does not replace human review. The feature only works when OpenRouter is configured in [Integrations](/admin/integrations#openrouter).
  </Accordion>
  <Accordion title="Automatic translations of event Rules" icon="scroll-text">
    A separate switch translates event Rules into the enabled non-English locales. It also requires OpenRouter. Review and correct translated Rules from the translation action in [Events](/admin/events).
  </Accordion>
  <Accordion title="What users will notice" icon="languages">
    Enabling a locale changes the site language selector and lets translated event titles and category labels appear in that language. If translations are disabled, users still see the locale, but content stays closer to the source language.
  </Accordion>
</AccordionGroup>

Automatic translations run in the background. Manual deployments need the translation enqueue and processing jobs described in [Scheduler Jobs](/manual-installation/scheduler-jobs). Enabling a switch does not translate every event immediately.
