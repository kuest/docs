## Prerequisites

- Working Kubernetes cluster and context
- Ingress controller available
- Base values from [Environment Variables](/configuration/environment-variables)
- A storage profile from [Manual Installation Overview](/manual-installation/overview)

## Baseline deploy

```bash
cp infra/kubernetes/secret.example.yaml infra/kubernetes/secret.yaml
```

Replace the placeholders in `secret.yaml`, set `SITE_URL` and `CHAIN_ID` in `configmap.yaml`, and select a tested image digest in `deployment.yaml`. Update the hostname, ingress class, and TLS secret in `ingress.yaml` for your cluster, and provision the certificate through your existing TLS setup.

```bash
kubectl apply -k infra/kubernetes
```

The baseline Kustomize resources do not run database migrations. Run `bun run db:push` from a secured environment with the production database connection, `SITE_URL`, `CRON_SECRET`, and selected storage profile before routing traffic to a release.

## Important configuration points

- `SITE_URL` must match the canonical public URL.
- In your copied `infra/kubernetes/secret.yaml`, set exactly one storage profile:
  - Supabase with `SUPABASE_*`
  - S3 with `S3_BUCKET`, `S3_ACCESS_KEY_ID`, and `S3_SECRET_ACCESS_KEY`

Verify the rollout before updating public DNS:

```bash
kubectl -n kuest rollout status deployment/kuest-web
kubectl -n kuest get pods,service,ingress
```

## Scheduler

If the supplied database jobs are not active, edit `infra/kubernetes/cronjobs.yaml` for your namespace, secret name, and `SITE_URL`. Before applying it, configure every endpoint and schedule listed in [Scheduled Jobs](/manual-installation/scheduler-jobs), using the same bearer header and secret reference.

Then apply the completed file:

```bash
kubectl apply -f infra/kubernetes/cronjobs.yaml
```

The jobs should follow [Scheduled Jobs](/manual-installation/scheduler-jobs).

## Optional Terraform

```bash
cd infra/terraform/environments/production/kubernetes
cp terraform.tfvars.example terraform.tfvars
terraform init
terraform plan
terraform apply
```
